# Source attribution and evidence limits

The project code is distributed under the [MIT license](LICENSE). That does not automatically license dataset questions or saved model text under MIT. No model weights are included.

| Original transfer fixture | CC0-1.0 declared in the saved fixture | Assigned answers; original bytes preserved locally |

Upstream license links describe those upstream artifacts, not authenticated provenance for every local question or response. Saved response-text redistribution terms and the embedded security/math questions' attribution are unresolved; this is a local review package, not a claim that all materials are cleared for public redistribution.

[Source verification receipts](data/provenance/README.md) separate current upstream item matches from collection-time evidence. Raw bundle provenance strings are preserved as source claims, not endorsed conclusions. The transfer fixture has a derived metadata-only cleanup; its scientific rows are unchanged.
