# Synthetic paired fixture

Original 16-item multiple-choice bank with 32 assigned answer rows. One eight-item bank has two gold keys per letter; the other has counts A=3, B=3, C=1, D=1. License declaration: CC0-1.0.

This is an authored regression fixture, not a model run or a published benchmark. The saved bundle is the offline input. Its release revision changes preparation prose only; original bytes are archived and all scientific rows are unchanged.

Use `eval-audit import --source examples/transfer-fixture/bundle.json --out NEW_DIR`. The [catalog](../../data/README.md) links independently verified reports. `authoring.py` records fixture construction; it refuses to overwrite an existing bundle.
